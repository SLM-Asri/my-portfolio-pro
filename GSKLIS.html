Internship Project

Gamified Student Knowledge System

Built by: S.L.M. Asri

A web-based student knowledge assessment system built with HTML, CSS, JavaScript, Node.js, Express.js, and MySQL. It uses gamified quizzes with scoring, levels, and progress tracking to boost student engagement, backed by secure JWT authentication and real-time dashboards.

View on GitHub Get in Touch Main Portfolio

Project Features

Secure JWT Authentication

Secure user registration and login built on JWT authentication, protecting student and admin accounts alike.

Gamified Quizzes

Scoring, levels, and progress tracking designed to make knowledge assessment engaging rather than a chore.

Real-Time Dashboards

Responsive dashboards for both students and administrators, with real-time performance monitoring.

MySQL Data Integration

A MySQL database powers user management, quiz data, and assessment results across the platform.
